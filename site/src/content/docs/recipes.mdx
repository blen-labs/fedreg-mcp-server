Each program runs as written in `execute`. They are plain JavaScript with top-level `await` and
`return`, each returns its result, and the repository tests each one. Under each program is what
it returned when it was captured, with the date and the source. The programs that use only the
Federal Register and the eCFR were run against the live APIs. The one that needs a regulations.gov
key shows labelled synthetic output.

## Tips

- **Filter first.** Each search takes one call, and a program has a call budget. One
  well-filtered search is better than many lookups.
- **Pass `fields` on every `fr.documents.search`.** Full documents are large.
- **Start with a small `per_page`**, 5 to 25. `count` gives the total for `fr`, and
  `meta.totalElements` for `regs`.
- **Use `getMany`** to read up to about 20 documents in one request.
- **Name a `part` for `ecfr.full`.** It returns the XML of a whole slice of the CFR.
- **Return less.** A returned value over 8 MiB fails with `ResultTooLarge`.
- **Use `facets`** to get counts by agency, topic, or date without the documents.

The [SDK reference](/reference/sdk/) lists every method.
